# Лабиринт

Мобильная игра-головоломка: исследуй лабиринт 6×6, записывай карту на листы и сопоставляй листы после падения в яму. Вынеси ларец через выход.

Статическое веб-приложение без сборки: откройте `index.html` (или `python3 -m http.server`).

- Экраны: старт, партия, пауза/настройки, итоги с настоящей картой и проверкой гипотез.
- Управление: стрелки/WASD, `M` режим, `F` взять клад, `Space` закрепить, `H` скрыть кальку, `Q`/`E` листы, `Esc` пауза; на телефоне — крестовина.
- Партия и настройки сохраняются в `localStorage`.

## Режим «Дуэль» (MVP)

Два игрока на одном экране, ведущий — сама игра (правила: [Циклопедия, «Лабиринт (игра на бумаге)»](https://cyclowiki.org/wiki/%D0%9B%D0%B0%D0%B1%D0%B8%D1%80%D0%B8%D0%BD%D1%82_(%D0%B8%D0%B3%D1%80%D0%B0_%D0%BD%D0%B0_%D0%B1%D1%83%D0%BC%D0%B0%D0%B3%D0%B5))).

- Каждая партия — новый случайный лабиринт 6×6: стены, 3 ямы по циклу, клад, госпиталь, арсенал, выход на краю.
- Игроки ходят по очереди, устройство передаётся через экран «Передай ход». У каждого свои листы и своя гипотеза карты; стартовая клетка неизвестна.
- Ведущий сообщает только тип клетки («пустая клетка», «яма», «госпиталь», «арсенал», «клад», «выход») или «стена». Номер ямы не называется, упор в стену тратит ход.
- Яма уносит в следующую яму цикла; стена или пропуск хода, пока стоишь в яме, тоже уносят.
- Действия: шаг, выстрел (пуля летит до стены или игрока), удар кинжалом (в своей клетке), пропуск хода. Арсенал даёт по 3 пули и кинжала, госпиталь лечит.
- Раненый не может стрелять и нести клад; клад остаётся там, где его ранили. Побеждает тот, кто вынес клад через выход.
- После партии открывается настоящая карта и проверка гипотез каждого игрока.

Пока вне MVP: реки, бомбы, цемент, медведь, ложный клад, игра по сети.

Создано по дизайну в Claude (Artifact «Лабиринт — полная партия»).
