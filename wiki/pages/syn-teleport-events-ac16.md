# Что перемещает игрока (вопрос по AC16 в duel-host-mode)

**Ответ: по источнику госпиталь и арсенал игрока не перемещают.** Базовые правила перемещают игрока только в двух случаях: падение в дырку и попадание в реку. Всё остальное, что связано с госпиталем, — оговорки и модификации. Источник неоднозначен в одном месте (см. ниже), поэтому окончательное слово за пользователем.

## Таблица

| Событие | Перемещает? | Основание |
|---------|-------------|-----------|
| Шаг в дырку, упор в стену из дырки, пропуск хода в дырке | Да, в следующую дырку по циклу | [[con-pit-cycle]] (базовое правило) |
| Вход в реку | Да, на две клетки по течению | [[con-rivers]] (базовое правило; в проекте вне MVP) |
| Пара «Яма — Выход» | Да, в свой выход | [[con-rule-modifications]] (модификация) |
| Вход в госпиталь | Нет, только лечение | [[ent-hospital]] (базовое правило) |
| Вход в арсенал | Нет, только пополнение запаса | [[ent-arsenal]] (базовое правило) |
| Ранение при нескольких госпиталях | Да, ведущий помещает раненого в госпиталь | [[con-rule-modifications]] (модификация, не в проекте) |

## Оговорка

Фраза «При попадании какого-либо игрока в госпиталь, дырку и т.п. для этого игрока начинает рисоваться отдельная схема» ([[con-paper-maps]]) ставит госпиталь рядом с дыркой как событие, рвущее схему. В базовых правилах для госпиталя перестановки нет, так что фраза либо неточна, либо подразумевает вариант «ведущий переносит раненого». Именно с такого прочтения мог появиться пункт «hospital/arsenal returns (teleports)» в AC16.

## Что это значит для AC16

- В проекте сегодня перемещают только падения в яму ([[syn-source-vs-app-rules]]). Разрыв маршрута нужен только для них.
- Предложение: сузить AC16 до падений в яму; общий маркер разрыва (▼/△ с буквой) оставить, чтобы он подошёл любому будущему переносу (реки, «раненый → госпиталь»). Решение о правке спеки принимает пользователь через `/requirements-eliciting`.

## Побочные наблюдения для спеки

- **Кто слышит ответ.** Источник: ведущий сообщает результат «игроку» ([[con-host-announcements]]). Решение D3 (публично обоим) — выбор проекта, не требование источника. Команды при этом произносятся вслух, поэтому направление выстрела слышно всем (D9 согласуется с этим).
- **Промах выстрела.** Источник прямо требует объявлять только ранение. «Мимо» в D9 — решение проекта.
- **Упор в стену** по умолчанию тратит ход ([[con-turn-actions]]); AC6 это и говорит.
