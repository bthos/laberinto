# Правила источника и приложение «Лабиринт»

Сравнение базовых правил из [[src-cyclowiki-labirint-igra-na-bumage]] с тем, что делает приложение (по `game.js` и `README.md`, прочитано 2026-11-04; это наблюдение за проектом, не ингестированный источник). Расхождений в базовых правилах нет, есть сознательные сужения.

| Тема | Источник | Приложение |
|------|----------|------------|
| Тип клетки в ответе, «стена» | [[con-host-announcements]] | то же; номер ямы не называется |
| Ямы по циклу, упор в стене из ямы, пропуск из ямы | [[con-pit-cycle]] | то же (`fall`) |
| Упор в стену тратит ход | [[con-turn-actions]] | да |
| Пуля летит до стены или до клетки с игроком | [[con-turn-actions]] | да |
| Кинжал ранит игрока в той же клетке | [[con-turn-actions]] | да |
| Арсенал: по 3 патрона, кинжала, взрывчатки | [[ent-arsenal]] | по 3 патрона и кинжала; взрывчатки нет |
| Госпиталь лечит; раненый не стреляет и не носит клад | [[ent-hospital]], [[con-wounds-and-treasure]] | да |
| Раненого с кладом: клад остаётся на его клетке | [[con-wounds-and-treasure]] | да |
| Реки, бомбы, цемент, медведь, ложный клад | [[con-rivers]], [[con-rule-modifications]] | вне MVP (README) |
| Схемы на бумаге, сопоставление | [[con-paper-maps]] | в классической дуэли в приложении; в режиме «с ведущим» на бумаге |
