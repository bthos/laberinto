# Действия за ход

Игроки ходят по очереди. За ход игрок делает одно действие ([[src-cyclowiki-labirint-igra-na-bumage]]).

| Действие | Правило по источнику |
|----------|----------------------|
| Перемещение | «вперёд», «назад», «вправо», «влево» (в 3D ещё «вверх», «вниз»). Только на соседнюю клетку (общая сторона, не по диагонали). Ведущий отвечает типом клетки или «стена». |
| Пропуск хода | Команда «пропустить ход». Из дырки пропуск переносит игрока в следующую дырку ([[con-pit-cycle]]). |
| Выстрел | «стреляю вправо». Пуля летит до первой стены или до клетки с другим игроком. Попавший ранен ([[con-wounds-and-treasure]]). |
| Кинжал | Если в клетке есть ещё кто-то, он ранен. |
| Взрыв стены | «взорвать стену справа». Три бомбы. |

- Упор в стену по умолчанию расходует ход. Вариант «ход не теряется» вынесен в [[con-rule-modifications]].
- Запас патронов, кинжалов, взрывчатки пополняется в [[ent-arsenal]]. В начале игры у игрока ничего нет.
- Раненый не может применять оружие ([[ent-hospital]] лечит).

См. [[con-host-announcements]] про то, что говорит ведущий в ответ.
